- 作家検索を「検索」タブ内へ統合
- 蔵書タブはシリーズ表示を主役にし、巻数順でまとめて表示
- ホームを新設し、「今日の発売」「これから7日間」「巻抜けチェック」に絞って表示
- 既存のISBN一括登録、スキャン、検索、価格、カレンダー、関連・おすすめ機能は維持
- 下半分スワイプのタブ移動も5タブ構成に更新
