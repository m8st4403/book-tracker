## v4.8.2 additions
- 作品名入力欄を巻数より広くした3:1レイアウト
- 購入状態：欲しい／予約済み／購入済み／購入しない
- 読書状態：未読／読書中／読了
- お気に入り・5段階評価・自分用メモ
- 発売日通知（試作：アプリ起動時に確認、通知許可が利用可能な環境では通知）
- 積読表示
- 作者プロフィール（登録蔵書一覧）
- 出版社プロフィール（登録蔵書一覧）
- ホームに積読／お気に入り冊数を表示
- 今月の残購入予定は購入済み・購入しない本を除外
- 既存のISBN 1冊1行・最大30冊・スキャン・検索・カレンダー・バックアップを継承

## 方針
個人の蔵書・購入・読書管理に特化。家族共有/SNS/読書時間管理は現時点では実装対象外。クラウド同期は将来のネイティブ版で検討。
