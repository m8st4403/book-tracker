# 本棚スケジュール v4.9.3

## 今回の追加
- カレンダーの日付を開いたときに表示される「発売予定」の各カードへ「＋ 蔵書に登録」を追加。
- 詳細画面を開かなくても、発売予定カードから直接蔵書登録できる。
- 詳細画面にも「＋ 蔵書に登録」を追加。発売予定カードから詳細を開いた場合も同じ登録ができる。
- すでに蔵書登録済みの本は「✓ 蔵書登録済み」と表示して二重登録を防止。
- ISBNがない発売予定は直接登録ボタンを無効化し、「ISBN未取得」と表示。
- 登録後はカレンダー表示を更新し、同じ発売予定が「蔵書登録済み」に切り替わる。
- iPhoneで押しやすいよう、登録・詳細ボタンは44px相当のタップ領域を確保。

## v4.9.2から維持している主な仕様
- ISBN一括登録は1行1ISBN、最大30行。ISBN-10/13対応。
- ISBN-10のXチェックデジットを内部で処理し、ISBN-13へ正規化。
- バーコード読み取りはBarcodeDetector対応時に利用可能。OCRによる表紙・背表紙タイトル認識は未実装。
- 蔵書・検索・著者検索・シリーズ管理・カレンダー・設定・バックアップ/復元。
- カレンダーは月単位。上部の月エリアだけ左右フリックで月移動。タブ移動はタップのみ。
- 今日・選択日は淡い色で表示。蔵書の発売予定日は「発売」マークで表示。
- カレンダー設定とカレンダー内の一時フィルターは分離。
- サンプル蔵書を初回起動時に表示してUIを確認可能。
- データは基本的に端末内保存。書誌検索時のみ通信。
