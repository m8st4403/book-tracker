# 本棚スケジュール v4.9.12 修正版

今回の修正:
- ISBN検索結果の同一ISBN重複を統合（ISBN-10/13も正規化）。
- ISBN追加検索後の「チェックした本を一括登録」ツールバーを登録後も維持。
- ISBN追加検索では行側の「登録対象」を使うため、検索結果ツールバーに不要な「全選択」を表示しない。
- 一般の作品検索・作者検索などの結果には「全選択」を表示し、selectAllを正しいcheckboxとして生成。
- 追加タブで「蔵書に登録」した直後も、検索結果カードが「✓ 蔵書登録済み」に更新される。
- 一括登録後も登録済み状態を即時反映。
- iPhone/Safariで「全選択」の四角が文字入力欄として表示される問題を修正。原因はselectAll inputにtype="checkbox"が欠落していたため。
- 開発版はAPP_VERSIONが変わるとサンプル削除状態をリセットし、サンプルを再生成。設定の「開発用：サンプルを再表示」も利用可能。
- サンプル削除後のメッセージ非表示CSS修正を継承。

App Store公開版ではDEMO_ENABLED=falseにしてください。
