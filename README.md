# 本棚スケジュール v4.6.1

v4.6.1 は v4.6.0 の動作確認結果を踏まえた安定化版です。

## 主な修正
- 初回起動時のカレンダーが表示されない原因を修正。
  - カレンダーフィルターの初期化が設定データの初期化より先に行われていたため、JavaScript が途中で停止する可能性がありました。
  - フィルターは安全な初期値で作成し、設定の読み込み完了後に同期します。
- 表示名保存後にヘッダー・ホームへ表示名が反映されない問題を解消。
  - 上記の JavaScript 初期化停止が原因でプロフィール保存処理まで到達しないケースを防止します。
- iPhone Safari の入力欄フォーカス時の自動ズーム対策を強化。
  - input / textarea / select を最終CSSで16pxに固定し、フォント設定変更によって15px以下にならないようにしました。
- タブは従来どおりタップ操作のみ。
- カレンダー上部のみ左右フリックで月を切り替えます。
