# Book Tracker v4.9.12 検索結果の蔵書削除反映修正版

## 今回の修正
- 追加タブの検索結果カードから、登録済みの本を直接「✓ 蔵書登録済み（タップで削除）」として削除できるよう修正。
- 詳細画面から蔵書を削除した場合も、詳細を閉じる前から背後の検索結果カードを最新状態へ更新。
- `removeBookFromCalendar()` の削除成功後に追加タブの検索結果を再描画する共通処理 `refreshAddResults()` を追加。
- ISBN検索結果と通常の作品検索結果の両方で登録状態が即時反映されるよう整理。
- 既存のISBN重複排除、チェックボックス修正、サンプルデータの開発者向け再表示仕様を維持。
