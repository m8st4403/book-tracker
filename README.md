# 本棚スケジュール v4.9.2

GitHub Pagesで動作するiPhone向け本棚・発売日カレンダー試作です。

## v4.9.2の変更
- 初回起動時のサンプル蔵書を、単行本1冊＋同一シリーズ2冊に整理
- 書籍詳細シートに「閉じる」ボタンを常時表示
- カレンダーの日付マークは黒い点を使わず「発売」ラベルに統一
- 選択した日・今日に当日の予定がない場合、当月の今後の発売予定（蔵書・関連図書・おすすめ書籍）を表示
- サンプルデータ表示中の案内を継続表示


### v4.9.2
- 初回起動日の相対日付でサンプル蔵書を過去・当日・未来に配置（7日前・当日・7日後）。
- 月末月初・年末年始をまたぐ場合も自動計算。
