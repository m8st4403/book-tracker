# 本棚スケジュール v4.8.9

v4.8.7をベースに、ホーム／蔵書／カレンダーの視認性と初回体験を改善。

- ホームと蔵書の統計カードを同じ薄い色付きデザインに統一
- 蔵書冊数：淡いブルー、蔵書総額：ブルーグレー、購入予定：淡いアンバー、積読：淡いラベンダー、お気に入り：淡いクリームイエロー
- カレンダーの「今日」と「選択中」を意味の異なる淡色で表示
- 今日：淡いブルー、選択中：淡いラベンダー、両方：淡い中間色
- 蔵書の発売予定日がある日は「発売」マークを表示し、カレンダー上の発売予定を視認しやすくした
- 初回起動時にサンプル蔵書3冊を自動登録し、未来の発売予定日の見え方を確認できるようにした
- サンプル蔵書には削除ボタンを用意。実際の蔵書登録前に削除できる
- 設定タブのバージョン表示を4.8.9へ更新
- JavaScript構文チェック、重複IDなどの静的デバッグを実施
