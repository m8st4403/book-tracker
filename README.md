# 本棚スケジュール v4.9.3

## v4.9.3 追加・確認事項

### カレンダー
- 発売予定カードに「＋ 蔵書に登録」を表示。
- 詳細画面を開かなくても、発売予定カードから直接蔵書登録できる。
- 詳細画面を開いた場合も「＋ 蔵書に登録」から登録できる。
- 登録済みの書籍は「✓ 蔵書登録済み」と表示。
- ISBNがない発売予定は登録ボタンを無効化。
- カレンダーで表示している月について、当日発売情報の下に「📚 今月発売された書籍」を追加。
- 「今月発売された書籍」には、その月の発売日が当日以前の書籍を発売日順でまとめて表示。
- 同一ISBN（ISBNがない場合は発売日＋タイトル）を重複表示しない。
- 月を切り替えると、その月に合わせて一覧も更新。
- 一覧内の各書籍にも、通常の発売予定カードと同じ蔵書登録・詳細表示導線を適用。
