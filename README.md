# 本棚スケジュール v4.9.2

GitHub Pagesで動作するiPhone向け本棚・発売日カレンダー試作です。

## v4.9.2で確定・反映済み

### 1. 基本ナビゲーション
- ホーム / 追加 / 蔵書 / 検索 / カレンダー / 設定の6タブ。
- タブ移動はタップのみ。
- カレンダー上部（月表示カード）だけ左右フリックで前月・次月へ移動。
- iPhone Safariでの二重タップ・誤操作を抑制。

### 2. ISBN登録
- ISBNは1冊1行、最大30冊。
- 入力欄は入力に応じて自動追加。
- 各行に登録対象チェックボックス、削除ボタン、検索状態を表示。
- ISBN-13とISBN-10を同じUIで扱う。
- 数字入力を基本とし、ISBN-10の末尾Xは先頭9桁からチェックディジットを補完してISBN-13へ正規化。
- 「ISBNをまとめて検索」で複数冊を一括照会。
- 検索結果は各行のチェック状態を引き継ぎ、チェックした本だけ一括登録。
- 重複ISBNは登録時に除外。

### 3. スキャン
- 「📷 本をスキャン」をISBN入力欄の上に固定配置。
- BarcodeDetector対応環境では連続ISBN読み取りに対応。
- 最大30冊まで読み取り、読み取り終了後にまとめて検索・登録。
- Safariで自動バーコード読取が利用できない場合は手入力へフォールバック。
- **OCRによる表紙・背表紙タイトル読み取りは未実装。ネイティブiOS化で追加予定。**

### 4. 作品・巻検索
- 作品タイトル＋巻数検索。
- 巻数未入力なら作品の全巻検索。
- 全巻検索時は発売日の新しい順を優先。
- 部分一致検索、クリアボタンあり。

### 5. 蔵書管理
- 作品名 / 作家名 / ISBN / 出版社で部分一致検索。
- 作者・出版社・発売年・発売日の絞り込み。
- 登録順、タイトル、作者、出版社、巻数、発売日などで並び替え。
- シリーズ表示、シリーズ・巻抜けチェック。
- 購入状態、読書状態、お気に入り、5段階評価、個人メモ、発売通知設定。
- ホームと蔵書の統計カードは共通ロジック・共通デザイン。
- 詳細画面からAmazon検索、出版社検索、関連書籍検索、カレンダー追加が可能。

### 6. 検索・作家・類似作品
- 書籍検索 / 作家検索を分離。
- 未登録のみ表示、検索結果数、並び順、日本語優先、未登録優先、キャッシュ設定。
- 作家の新刊チェック。
- 類似作品検索：絵・作画 / ストーリー / ジャンル / 作家・作風 / 舞台・世界観 / 雰囲気。
- 検索結果・蔵書は詳細ページへ遷移可能。

### 7. カレンダー
- 月単位表示。
- 今日・選択日は淡い色で表示。
- 蔵書の発売予定は黒点ではなく「発売」ラベルで表示。
- 関連図書・おすすめは日付をタップして確認。
- 選択日などに予定がない場合、当月の今後の予定を表示するフォールバックを実装。
- カレンダー内の「蔵書 / 関連 / おすすめ」は一時的な表示フィルター。
- 設定のカレンダーフィルターは初期値として使用し、カレンダータブ内の一時フィルターとは独立。
- **「カレンダーを開いたら今日を表示」はデフォルトON。** ユーザーがOFFにした場合は端末内設定として保存。
- iPhoneカレンダー用ICS出力。

### 8. 初回デモ
- 初回起動時、サンプル蔵書を3冊表示。
- 「月夜の標本」＝7日前、「星の余白 1巻」＝当日、「星の余白 2巻」＝7日後。
- 同一シリーズ2冊でシリーズ表示の見え方も確認できる。
- サンプル蔵書削除ボタンあり。
- 既存のv4.9系デモデータは初回日基準へ移行する。

### 9. 設定・データ
- プロフィール、テーマ、文字サイズ、自作スキン、背景画像、文字色自動補正。
- JSONバックアップ / 復元。
- アプリ管理対象のlocalStorageのみをバックアップ・復元し、localStorage全消去は行わない。
- 検索操作以外は原則端末内で動作。
