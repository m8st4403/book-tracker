# 本棚スケジュール v4.9.4

## カレンダー表示改善版
- 前月・翌月のサンプル発売日は月内15日固定。月の日数が異なる場合でも日付がずれません。
- 日付を選択したときの発売予定表示を「yyyy-mm-dd の発売予定」に統一。
- 発売予定がない日は「なし」と表示し、過去・現在・未来で表現を変えません。
- 月単位のカードは表示中のカレンダー月を基準にします。
- 現在より未来の月は「○月に発売予定の書籍」、現在月・過去月は「○月に発売された書籍」と表示します。
- 月を切り替えた際も、その表示月の情報だけを表示します。


### v4.9.4 demo data
- 前月15日：蔵書として登録済み
- 7日前：発売済み・蔵書未登録（カレンダーから登録可能）
- 当日：発売日サンプル・蔵書未登録
- 7日後：発売予定・蔵書未登録
- 翌月15日：発売予定・蔵書未登録
