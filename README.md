# 本棚スケジュール v4.5.5

v4.4.9〜v4.5.2までの実装を維持しつつ、起動停止の原因になり得る箇所とCSSを整理した安定化版です。

## 主な修正
- localStorageの壊れたJSONで起動停止しないよう安全読み込みを追加
- `books_v41` / `calendarExtras_v442` も安全読み込み化
- v4.5.2〜v4.5.3で混入していた `addBook` 周辺のコード結合ミスを修正
- 起動時にホームだけを表示し、他タブはhidden属性でも確実に非表示化
- タブ切替をイベント委譲方式に整理し、ボタン／タップ領域の競合を低減
- タブのフリック判定をcontent領域に限定し、下半分のみタブ遷移
- カレンダー上部は月変更、下部はタブ遷移として明確に分離
- 設定値の型・範囲を起動時に正規化
- 保存済みカレンダーフィルターを画面にも反映
- CSSを複数の追記styleから1つのstyleへ統合
- 旧CSSの上書き競合を整理し、テーマ変数を中心にした構成へ
- ランタイムエラー時に画面上へ最低限のエラー表示を追加
- オフライン動作を維持し、通信は検索操作のgetJSONからのみ

## 4.4.9〜4.5.2で固めた機能
- ホーム画面・蔵書総額・近日発売
- 設定タブ、プロフィール、テーマ、文字サイズ、自作スキン、背景画像、文字色自動補正
- バックアップ／復元
- 検索設定、カレンダー設定、このアプリについて
- 蔵書／関連／おすすめのカレンダーフィルター
- カレンダー上部フリック＝月変更、下部フリック＝タブ移動
- シリーズ表示、巻抜けチェック、未登録優先／未登録のみ検索
- 詳細ページ、Amazon検索、出版社検索、関連書籍検索
- 複数ISBN一括検索、ISBNスキャン
