# 本棚スケジュール v4.7.0

## 今回の見直し
- 全6タブのUIを共通デザインへ統一。
- iPhone幅での折り返し・はみ出しを抑制。
- 入力欄を16px以上にしてSafariの自動ズームを抑制。
- 蔵書の検索・並び順・絞り込みを整理。
- 検索タブのモード切替と検索操作を整理。
- 設定タブの各カード・選択状態・バックアップ操作を整理。
- カレンダーの月移動・今日・日付選択・表示フィルターの操作領域を整理。
- 下部タブはタップのみ、カレンダー上部のみ左右フリックで月移動。
- localStorageへの蔵書・カレンダー保存を共通化して失敗時のデータ破損を抑制。
- バックアップ／復元は本アプリが使用するキーだけを対象にし、サイト内の他データを消去しないよう変更。
- 重複していた登録処理を1つに整理。
- バックアップのアプリバージョン表示を4.7.0に統一。

## オフライン方針
通常の蔵書表示・編集・削除・カレンダー・設定・バックアップ／復元は端末内データを使用します。書誌情報の検索・ISBN照会など明示的な検索操作ではインターネットを使用します。
