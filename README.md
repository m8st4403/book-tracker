# 本棚スケジュール v4.9.8

v4.9.9をベースに、サンプルデータ削除の確認UIとサンプル登録後の削除対象判定を修正した試作版です。

- サンプル書籍を蔵書登録しても `demo` 属性を維持し、サンプル削除の対象から外れないよう修正。
- ホームのサンプル表示メッセージを、サンプルデータが存在する間だけ表示。
- サンプル表示メッセージをタップすると削除確認を開ける。
- 削除確認は YES / NO ボタンで選択。
- 設定の削除ボタンも同じ確認を使用。
- 削除成功後はサンプル表示メッセージと削除ボタンを非表示。
- サンプル削除は蔵書とカレンダー追加の両方を対象にし、通常の蔵書には影響しない。
