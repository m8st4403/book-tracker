# 本棚スケジュール v4.5.1

## 今回の変更
- テーマ（UIブルー／ナチュラル／ダーク）がアプリ全体へ反映されるよう修正。
- 自作スキンもアプリ全体へ反映。
- iPhone内の写真・画像を背景に設定可能。画像は端末内向けに圧縮保存。
- 背景色／背景画像に合わせて文字色の明るさを自動補正。色相・彩度をできるだけ維持し、コントラストを確保。自動補正はオン／オフ可能。
- 「検索・ISBN照会などの検索操作」だけがネットワークAPIを使う構成に変更。通常の閲覧・編集・削除・カレンダー・設定・バックアップ／復元は端末内データのみ。
- 検索結果の外部カバー画像は検索画面でのみ表示し、登録済み蔵書はリモート画像に依存しない。
- 設定画面に「データ管理：バックアップ／復元」を追加。JSONファイルで端末内データを保存／復元。

## バックアップについて
バックアップJSONには、このアプリのlocalStorageデータをまとめて保存します。復元すると現在のlocalStorageをバックアップ内容に置き換えます。

## App Store版への発展
最終的なネイティブiPhone版では、SwiftData等のローカルDB、端末内画像キャッシュ、EventKit等を利用することで「検索だけオンライン」の思想をより確実に実装できます。
