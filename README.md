# 本棚スケジュール v4.8.3

## 今回の主な変更
- ホームと蔵書タブの「蔵書冊数・蔵書総額」を同じ統計カードUIに統一
- 購入予定・積読・お気に入りも同じ統計カードUIで表示
- ホーム／蔵書の統計値を共通の派生データ計算ロジックから取得
- 購入済み・購入しない本を購入予定集計から除外
- 書籍メタデータ変更時にホーム／蔵書の関連統計も更新
- 作品名入力欄を巻数より広くしたv4.8.1以降の仕様を継承
- 個人の蔵書・購入管理に特化する方針を維持
