# 本棚スケジュール v4.4.8

v4.4.7をベースに、UIデザイン案との見た目の統一を進めたバージョンです。

## 今回の変更
- ホームの3つの情報カードの下に「🔥 近日発売の注目書籍」を追加
- 今日から30日以内の発売予定から最大3冊を表示
- 表紙・タイトル・発売日・「蔵書 / 関連 / おすすめ」バッジを表示
- 「すべて見る」からカレンダーへ移動
- 近日発売表示はカレンダーの表示フィルターに左右されず、発売予定全体から表示
- 既存の機能・項目は削除せず、配色、余白、角丸、ボタン、入力欄、カード、シリーズ表示、検索切替、カレンダーなどの見た目をUIデザイン案に近づけて調整
- カレンダーは日曜・祝日を赤、土曜を青、今日を青枠で表示
- 下部5タブの選択状態は青色＋上部ラインで表示

## 既存機能
- ISBN-10 / ISBN-13の登録・複数ISBN対応
- カメラスキャン
- 作品名＋巻数検索
- 蔵書のシリーズ表示・巻抜けチェック
- 蔵書フィルター・並び替え・総額集計
- 本の検索・未登録のみ表示
- 作家検索・新刊チェック
- 類似作品検索
- カレンダー表示・蔵書/関連/おすすめフィルター
- iPhoneカレンダー用ICS出力
- 書籍詳細・Amazon/出版社/関連作品への導線
