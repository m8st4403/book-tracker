# 本棚スケジュール v4.4

v4.3をベースに以下を追加・修正。

- フリック開始エリアを画面下半分に限定
- カレンダー内の左右フリックは月移動を優先
- ISBNなどの入力欄を見切れにくく調整
- 入力欄に×クリアボタン
- ISBNの複数冊検索（改行・スペース・カンマ区切り、最大30冊）
- 検索結果/蔵書から書籍詳細シートを開くための汎用フック
- 詳細に紹介、著者、出版社、発売日、ISBN
- 詳細からAmazon検索、出版社検索、関連書籍検索
- 関連書籍は著者・タイトルを軸にしたプロトタイプ検索

注意：関連書籍の高度な類似度判定や出版社公式ページの正確な自動取得は、次段階のAPIプロキシ（Cloudflare Worker）で強化する想定です。
